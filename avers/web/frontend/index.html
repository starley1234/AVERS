Как это работает:
1. Каждый ROI (256×256) кодируется CLIP ViT-B/32 → 512d embedding
2. Хранится в FAISS / Qdrant с метаданными (label, bbox, описание)
3. При коллизии: retrieve Top-K похожих → prompt в VLM с примерами (few-shot)
4. VLM отвечает с учетом контекста примеров → более точное решение
