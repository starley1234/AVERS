# Reference Schematics — материал для Active Learning Loop (v0.3)

Это **небольшая курированная выборка** реальных советских/российских
электрических схем, расположенная по уровням сложности (simple → complex),
как попросил пользователь. Она нужна, чтобы:

1. сразу иметь материал для smoke-теста пайплайна АВЕРС на *настоящих*
   (не синтетических) изображениях;
2. дать агенту/инженеру на GPU-машине отправную точку для разметки через
   `/annotator` и первых циклов Active Learning (v0.3), прежде чем качать
   датасеты в больших объёмах.

Полный каталог источников (с дополнительными ссылками, количеством схем на
сайт, лицензионными примечаниями и инструкцией по масштабированию) — в
[`docs/REAL_SCHEMATICS_SOURCES.md`](../../docs/REAL_SCHEMATICS_SOURCES.md).

## Структура

| Папка | Сложность | Что внутри | Зачем |
|---|---|---|---|
| `tier0_gost_symbols/` | тривиально | Чистые таблицы УГО по ГОСТ 2.721-74 | Сверка отрисовки символов в `avers/dataset/gost_symbols.py`, визуальный reference |
| `tier1_simple_car/` | просто | Схемы электрооборудования ВАЗ-2101/2102 (Э4-подобные) | Ближайший открытый аналог простой БКС: разъёмы, пронумерованные контакты, цветовая маркировка проводов, "массы" |
| `tier2_medium_radio/` | средне | Принципиальные схемы ламповых радиоприёмников СССР | Аутентичные артефакты скана (шум, наклон, выцветшая печать) — тренировка устойчивости OCR/детекции |
| `tier3_complex_truck/` | сложно | Схема электрооборудования КамАЗ-5490 | Высокая плотность элементов, близко по масштабу к реальной многолистовой БКС |

`manifest.json` в этой директории содержит для каждого файла: `title`,
`source_url`, уровень сложности и описание. **Используйте его**, если
нужно процитировать источник или проверить лицензию перед дальнейшим
использованием.

## ⚠️ Лицензия / использование

Эти изображения — скан-копии со сторонних энтузиастских/справочных сайтов
(форумы автолюбителей, архивы радиолюбительских схем, ГОСТ-справочники).
Они включены **только для внутренней разработки и тестирования** (active
learning, smoke-тесты pipeline). Перед любым публичным/коммерческим
использованием:

- проверьте права на каждый конкретный источник (см. `source_url`);
- не публикуйте и не распространяйте эту папку отдельно от приватного
  проекта;
- для продакшн/релизных датасетов предпочитайте: собственные сканы БКС,
  синтетику (`avers/dataset/synthetic.py`), либо датасеты с чёткой
  открытой лицензией (CC BY 4.0 / MIT) — см. `PUBLIC_DATASETS.md`.

## Как использовать прямо сейчас

```bash
# Прогнать пайплайн на реальной (не синтетической) схеме
python -m avers process data/reference_schematics/tier1_simple_car/vaz_2101_wiring_01.jpg \
    --output /tmp/vaz_2101_result.json

# Или открыть в Web UI валидаторе и разметить вручную через /annotator
python -m avers web --port 8000
```

## Масштабирование на GPU-машине

Этот набор специально маленький (12 изображений, ~1 МБ) — он не предназначен
для обучения с нуля, только для smoke-теста и затравки active learning. Для
реального дообучения:

1. Прочитайте `docs/REAL_SCHEMATICS_SOURCES.md` — там полный список
   источников по каждому уровню сложности с оценкой объёма доступного
   материала.
2. Скачайте больше схем того же уровня вручную/скриптом (уважая robots.txt
   и условия сайтов) и положите в `data/reference_schematics/<tier>/raw/`
   (эта поддиректория в `.gitignore`, в git не попадёт).
3. Разметьте через `/annotator` → экспортируйте YOLO → добавьте как
   источник в `avers.dataset.merge.merge_datasets` наравне с synthetic и
   feedback датасетами (см. `docs/ACTIVE_LEARNING_V03.md`, раздел
   "Merge synthetic + feedback + real").
