# Библиотека ГОСТ УГО и CPU-детектор без обученных весов (v0.4)

## Что это

* `avers/dataset/gost_symbols.py` — библиотека из **31 класса** УГО по ЕСКД:
  геометрия в миллиметрах (вместе с отрезками выводов), координаты выводов,
  буквенный код по ГОСТ 2.710-81, тип компонента. Классы 0–9 сохранены с v0.1
  (совместимость весов и разметки), новые добавлены с id 10.
* `avers/stages/stage2_detection/template_detector.py` — `GOSTTemplateDetector`,
  детектор УГО на чистом OpenCV. Включается автоматически, если в конфиге нет
  `detection.model_path` (`detection.template_fallback: true`).
* `avers/dataset/demo_schematic.py` — демо-схема БКС с эталонным netlist
  (`data/demo_bks_schematic.png` + `.netlist.json`) и функция `evaluate()`.

## Как работает детектор

1. Бинаризация (Otsu), толщина линии = площадь штрихов / длина скелета.
   Если штрихов > 30 % площади, это не чертёж, и детектор ничего не возвращает.
2. Масштаб px/мм оценивается по опорным символам на вдвое уменьшенной копии.
   Диапазон масштабов ограничен толщиной линии УГО 0,15–0,8 мм.
3. Нормированная корреляция размытых карт штрихов с шаблонами, отрисованными
   той же функцией библиотеки: 4 поворота, плюс зеркало для несимметричных УГО.
4. Каждый кандидат проходит проверку по пикселям:
   * тело символа (без отрезков выводов) покрыто штрихами ≥ 85 %;
   * «лишних» штрихов внутри окна ≤ 25 % (резистор ≠ предохранитель);
   * кольцо вокруг окна пусто, кроме проводов из выводов (символ изолирован,
     а не является фрагментом другой фигуры);
   * хотя бы к одному выводу подходит провод (иначе это, скорее всего, текст);
   * штрихи не лежат почти целиком на оси выводов (иначе это просто провод).
5. NMS: при близких оценках побеждает символ, который объясняет больше штрихов
   (светодиод > диод, кнопка > контакт).
6. Отдельно ищутся разъёмы-таблицы (стопка ≥ 2 одинаковых ячеек; провод через
   прямоугольник таблицей не считается) и точки соединения (ядро толще линии
   и ≥ 2 отходящих провода).

Каждая детекция содержит выводы, поэтому графовый синтез выдаёт netlist
«компонент:вывод». Точки соединения используются как узлы графа и в netlist не
попадают. Разъём объединяет провода по обе стороны одной ячейки (контакт
стыкуемых жгутов).

## Проверено (CPU, без ML-библиотек)

* Демо-схема: 19/19 компонентов, 11/11 цепей, точность 100 %.
  То же при масштабе ×0,75 и ×1,35, шуме σ=18, размытии, JPEG q=60 и низком
  контрасте. Время ≈ 5 с на 1600×900.
* Каждый детектируемый класс по отдельности, в 4 поворотах
  (`tests/test_gost_library.py`).
* Квадрат с проходящим через него проводом, шум и голые провода не дают
  ни одного УГО.

## Ограничения

* Без OCR позиционные обозначения назначаются по ГОСТ 2.710-81 по порядку
  (сверху вниз, слева направо). Например, контакт реле K1.1 получит `SA2`.
  Реальные обозначения требуют OCR-бэкенда (PaddleOCR / EasyOCR).
* Сканы из `data/reference_schematics/` (интернет-картинки низкого качества,
  старые нестандартные УГО, радиолампы) распознаются плохо. Шаблонный детектор
  рассчитан на чистые схемы по ЕСКД (CAD / качественный скан). Для остального
  нужна обученная модель (`avers dataset train` на GPU), и библиотека для неё
  же генерирует синтетику.
* Масштаб оценивается по опорным символам (R, FU, EL, VD, K, SA, C, GB). На
  листе вообще без них задайте `detection.template_px_per_mm`.

## Сопутствующие исправления пайплайна

* `GraphBuilder.merge_collinear_segments/build_graph`: k-d tree и сетка вместо
  O(n²)/O(n³). `test_very_large_image` и реальные сканы раньше зависали.
* `WireVectorizer`: открытие 3×3 только для толстых линий (раньше стирало линии
  тоньше 3 px), порог Hough 20 (короткие провода между УГО), продление концов
  отрезков вдоль штриха до углов и выводов, удаление дублей и изолированных
  коротких отрезков (штрихи рамки, буквы), глобальная маска Otsu против шума бумаги.
* Выводы, лежащие на краю bbox, перед привязкой сдвигаются наружу на величину
  выреза векторизации (`vectorization.snap_radius`).
* Цепь из одного неподключённого вывода больше не попадает в netlist.

## Запуск

```bash
python -m avers web            # http://127.0.0.1:8030 → «▶ Демо-схема БКС (ГОСТ)» → «Запустить»
python -m avers.dataset.demo_schematic data/demo_bks_schematic.png   # перегенерировать демо
python -m pytest tests/test_demo_schematic.py tests/test_gost_library.py -q
```
