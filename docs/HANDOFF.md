## 1. Что это сейчас умеет (рабочий прототип)

Растровая или PDF-схема по ЕСКД → компоненты (УГО) с выводами и позиционными
обозначениями → netlist «компонент:вывод». Работает **на CPU без обученных
весов**.

| Стадия | Чем сделано | Статус |
|---|---|---|
| OCR | EasyOCR + `avers/core/designators.py` (ГОСТ 2.710, `K1.1`, повторный проход). С 16.10 выполняется **до** детекции | работает |
| Детекция УГО | `GOSTTemplateDetector`: шаблоны библиотеки ГОСТ (31 класс), оценка масштаба, различение близнецов | работает |
| Разъёмы-таблицы, точки соединения, сетки-таблицы | там же | работает |
| Векторизация проводов | `WireVectorizer` (Otsu → скелет → Hough → продление по штриху) | работает |
| Граф / netlist | `GraphBuilder` + мосты между соседними выводами (`_pin_bridges`) | работает |
| Генератор схем v2 + датасет YOLO | `avers/dataset/schematic_gen.py`, `cli generate-v2` | работает |
| Обучение | `avers/dataset/train.py`, `cli train` | исправлено, проверено 1 эпохой на CPU |
| Обученные веса | `UltralyticsTiledDetector` + гибрид `refine()` | подключено, **модели нет** |
| Web UI, PDF, экспорт | FastAPI `avers/web` | работает |

## 2. Как запустить (Windows)

```
cd C:\github\AVERS
start.cmd                 # фон, открывает http://127.0.0.1:8030 ; логи в logs\
stop.cmd
```
В UI: «▶ Демо-схема БКС (ГОСТ)» → «Запустить обработку».

Проверки из консоли:
```
venv\Scripts\python.exe -m pytest tests -q                  # 265 passed (с EasyOCR), ~3,5 мин
venv\Scripts\python.exe scripts\stress_demo.py --fake-ocr   # демо, 10 вариантов, ~1,5 мин
```

`venv` — общий из `C:\github\AVERS\venv`. Для `-m avers...` из другой папки
задайте `PYTHONPATH` на корень репозитория.

## 7. Ловушки (не наступать повторно)

- `opencv-python` vs `opencv-python-headless`: ultralytics ставить только
  `--no-deps`. Экспорт ONNX и прочие «удобства» ultralytics сами
  доустанавливают пакеты — поэтому ONNX в `train.py` выключен по умолчанию.
  Скачанные веса (`yolo11n.pt`) ultralytics кладёт в **текущую папку**:
  запускать обучение не из корня репозитория.
- PowerShell 5.1: `.ps1` с кириллицей — только UTF-8 **с BOM**; в `.cmd` —
  только ASCII. Однострочники `python -c "..."` с кавычками внутри PowerShell
  ломает — писать временный `.py`.
- Консоль Windows (cp1251/cp866) падает на `×`, `σ`: в скриптах
  `sys.stdout.reconfigure(errors="replace")` или `PYTHONIOENCODING=utf-8`.
- Чтение JSON/текста в тестах на Windows — явно `encoding="utf-8"`.
- Hough вероятностный: любые «фиксированные пиксельные» допуски проверять на
  ×3 масштабе **и** на листах 4–5 px/мм (бенчмарк).
- Модуль, загружаемый `importlib.util.module_from_spec` с `@dataclass`,
  нужно положить в `sys.modules` до `exec_module`.
- В эталоне демо X1:1 и X1:3 объединяют цепи по обе стороны контакта — это
  намеренно.
- Номера позиций ГОСТ 2.710 начинаются с 1: `R0` — ошибка OCR.
- Подставной OCR должен давать рамки там, где текст на самом деле: прежние
  угаданные рамки над УГО накрывали соседние символы, и фильтр «УГО внутри
  текста» удалял настоящие заземления.
